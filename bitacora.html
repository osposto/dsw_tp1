Bitácora del Proyecto

Registro cronológico de decisiones de diseño, problemas técnicos y soluciones aplicadas durante el desarrollo del TP1.

1. Estructura Base y Breakpoints

Fecha: Inicio del Proyecto

Decisiones tomadas: Se optó por una reconstrucción completa ("desde cero") del repositorio para cumplir estrictamente con los requisitos de la rúbrica. Se diseñó un tema oscuro (Dark Theme) centralizado en un archivo styles.css y se implementó una barra de navegación persistente para evitar por completo el uso del botón "Atrás" del navegador.

Dificultades encontradas: Asegurar que la grilla del equipo se adaptara perfectamente sin desbordes a los 3 anchos de pantalla exigidos (400px, 900px y 1200px).

Soluciones aplicadas: Se utilizó CSS Grid nativo combinado con Media Queries (@media min-width) para reestructurar dinámicamente las columnas: 1 columna en móviles, 2 en tablets y 4 en pantallas de escritorio grandes.

2. Optimización de Imágenes e Interactividad JS

Autor: Orlando Sposto

Decisiones tomadas: Integrar dos funciones dinámicas en JavaScript: un buscador en tiempo real en la portada que filtra por habilidades/nombre, y un modal interactivo en el perfil individual para visualizar pósters, sinopsis y datos de películas favoritas.

Dificultades encontradas: 1) Diferentes dimensiones en las imágenes de pósters y portadas de discos rompían la asimetría visual. 2) Se experimentó un bucle infinito (infinite loop) en el navegador causado por una etiqueta onerror en una imagen local borrada, lo que bloqueaba la carga de la página.

Soluciones aplicadas: Para las imágenes, se implementó la propiedad CSS object-fit: cover con dimensiones fijas para recortes perfectos. Para el fallo del bucle, se reemplazaron temporalmente las imágenes rotas con la API externa de ui-avatars.com hasta que las fotos oficiales en formato optimizado .webp fueron re-subidas a la carpeta img/.
